How to use the studio

  1. Start with Class XI foundations; use Class XII when you are ready for the next layer.
  2. Read the explanation and rework the example on paper.
  3. Move the sliders and predict the result before looking at the readout.
  4. Answer the quick check, solve both problems and compare reasoning with the solutions.
  5. Use the notebook for two substantial project investigations.

These 41 concept lessons group related syllabus skills. They provide a foundation and practice set, rather than an exhaustive textbook or collection of every examination question type. The coverage labels identify the skills introduced in each lesson; some advanced subcases will need further worked practice.

Scope notes: Class XI includes statistics, complex numbers and conics. Class XII includes planes, matrix methods and first-order differential equations. Second-order equation solving and vector proofs of geometric theorems are excluded in the supplied theory scope. Random-variable variance and binomial distributions appear in suggested project work, beyond the Class XII theory focus on distributions and means.
