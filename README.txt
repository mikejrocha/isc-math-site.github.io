MATH STUDIO — ISC MATHEMATICS 2027

GET STARTED
1. Extract the entire ZIP to a directory.
2. Double-click index.html in a modern browser.
3. Select Class XI or XII, search a concept, and open a lesson.

No installation, internet connection, server, fonts, CDN, or build step is required.
All CSS, JavaScript, lesson content, and vector diagrams are embedded into each HTML page.
Keep the HTML files together for the relative navigation links to work. An individual
concept file can be copied and opened independently; its own activity, quiz and problems
will still work, but navigation requires neighbouring pages.

CONTENTS
index.html             Searchable concept library
41 concept HTML files  Explanations, examples, sliders/diagrams, 41 quick checks,
                       and 82 numeric problems with hints and worked solutions
syllabus-map.html      Class XI/XII routes, weightings and scope notes
project-work.html      Project prompts, rubric and editable downloadable notes

HOW TO STUDY
Read the explanation; solve the example independently; predict slider changes; test
your understanding with the quick check; solve the two practice problems on paper.
The answer checker accepts decimals, fractions and scientific notation, with a 0.1%
relative tolerance and 0.001 absolute minimum tolerance. It checks the numeric result,
not the method. Compare your working with the revealed solution.

SAVING PROGRESS
Completion is manually marked. Progress uses localStorage when the browser permits it.
Browser rules for file:// storage vary: progress may be isolated per HTML file or cleared
by private browsing. The activities do not depend on storage. Use Export progress on
the homepage regularly. Import merges a backup and asks you to refresh lesson controls.
For consistent cross-page persistence, you may optionally serve this folder using your
own local static server, but the lessons themselves require no server.
Project notes are saved separately; use Download notes to retain them.

ACCESSIBILITY
Keyboard-operable controls, native range sliders, labelled inputs, SVG text descriptions,
responsive layouts, skip links, and explicit play/pause controls. Animation never starts
automatically. Plots are explanatory diagrams; some axes use unequal scales, as noted.
In live diagrams the numeric readout is the precise source of computed values.

SCOPE AND SOURCE
Based on the supplied 17.-ISC-Mathematics.pdf: ISC Examination Year 2027 Mathematics
(860), containing both Class XI and XII. All teaching prose, problems and diagrams were
created for this site. The original PDF is not redistributed. Lessons group related
syllabus skills into 41 introductions; this is not an exhaustive examination textbook.
The syllabus map identifies coverage and exclusions. Suggested project content is
separated from the theory material. This is an independent resource, not an official
CISCE publication. No analytics, accounts, external requests or user-data transmission.
